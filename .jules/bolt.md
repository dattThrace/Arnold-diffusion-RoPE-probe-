## 2025-05-25 - [Pre-allocate Loop Variables for Math Loops]
**Learning:** In tight inner loops running computationally intensive math simulations (like deep learning optimizers/attention approximations in typescript), instantiating `Float64Array` heavily fragments memory and causes significant slowdowns due to GC and constant memory allocation. By pulling arrays (like `Qp`, `Kp`, `logits`, `exps`, and `A`) to class members and instantiating them once, we can double the processing speed. Furthermore, manually unrolling short inner loops (e.g. dot products where `d=4`) also yields substantial performance gains over naive loop accumulation in JS/TS.
**Action:** When working on performance optimizations in TS simulation or mathematical code, check for large array allocations inside tight loops and pull them out into class fields or outer scope variables. Also, check for opportunities to unroll short constant-sized loops.
